# MetaPreviews — Open Graph & Meta Tag Asset CDN

Welcome to the central repository for static preview assets used across my web projects, applications, and portfolios.

---

## 📷 Purpose of this Repository

This repository acts as a lightweight, dedicated **Asset Content Delivery Network (CDN)** via GitHub Pages. It hosts high-resolution open-graph images (`og:image`), thumbnail previews, and metadata-related cards for my various web architectures. 

When search engines, communication platforms (like Discord, Slack, WhatsApp), or professional networks (like LinkedIn) crawl the `<meta>` tags of my live websites, they retrieve the absolute image links hosted dynamically within this repository.
